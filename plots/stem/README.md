# Stem

Stem prepares a member Seed to add another Host to an existing Body.
Its checked Source invokes `stem/prepare` with finite request and outcome
Types. The producing Body must retain the exact invitation, Host configuration,
and effect authority before the selected Back can prepare the Seed. Starting
the recipient, authenticating its Join, and admitting its Part are separate.

Stem uses `conduit.host/stem-prepare@1`. The historical
[`womb/main`](../womb/README.md) Source remains available for inspection.
Its checked identities, requests and receipts belong to the original contract.
The current browser runtime accepts the Stem preparation contract.

Repository contract checks enter through `cargo xtask check crib-preparation`.
