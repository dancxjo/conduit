# Crèche

`main.conduit` is an ordinary checked Plot invoking the `creche/prepare` Kind.
It prepares another Body from an existing Body through one exact admitted Host
operation. It contains no target, filesystem, toolchain or deployment facts. Each invocation
accepts one exact request and settles after one classified outcome; an empty
closed request is invalid rather than an encounter that waits indefinitely.

The 32-byte request identifies retained owner-admitted encounter state. It is
not itself an authority grant. Host preparation must bind it to the actual
producing Body, Plan and Play, reviewed catalogues, selected operations, resources,
finite work and storage bounds, and authority. The Host operation runs the
canonical `DeploymentEncounter`, validates actual acknowledged MaskShows, and
crosses the ordinary make/carrier boundaries. It must not replace canonical
FaceInteraction with a private event protocol.

The 65-byte typed outcome preserves the exact request identity, a classified
Prepared/Realized/Refused/Cancelled disposition, and the digest of retained
canonical receipts or classified refusal/cancellation evidence. Prepared means
media preparation; Realized additionally references carrier effects. Neither
asserts that a machine booted or joined. The Host must retain and verify that
evidence before completing the call; the kernel Back cannot establish evidence
custody by inspecting a digest. Mechanism denial/failure/cancellation remains a
distinct Host Call outcome. Output pressure retains the completion without
repeating the effect. The installed execution owner must cancel and drain any platform effect before
hard kernel retirement. `FixedScheduler::cancel()` revokes pending ownership and
rejects late completion; it does not dispatch a platform cancellation by itself.

The model and allocation-free StepBack live in `conduit-body-make`'s
`deployment_runtime` module. The source catalogue is in
`deployment_runtime_catalog`. An installed consumer must select the exact Back,
Host Call binding and bounded queues through ordinary planning/lowering.
Source checking and kernel conformance alone do not prove an installed native
interactive encounter, image production, device writing, boot or join.
