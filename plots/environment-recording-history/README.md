# Original recording inspection

`main.conduit` is a closed semantic Plot: a cadence requests an existing recorded
quantity snapshot and projects it as an inspection Face. Host, storage, producer
selection and authority belong to the checked hosted IMAGE and trusted Root.

Repository proof entrances:

- `cargo xtask prove environment recording-source`
- `cargo xtask prove environment recording-selected-host`
- `cargo xtask prove environment recording-owner-mask`

The Linux Source captures one explicitly selected immutable original JSON record
before Play and retains frozen bytes. It does not run a recorder or authorize
producer retirement. The selected tail is bounded; this inspection does not
replace the legacy full-history consumer. See
[the extraction audit](../../docs/audits/environment-extraction.md) for acceptance
gates and proof limits.

Checked initialization supplies all sixteen fields explicitly. The Make template
uses a tail of eight; its defaults do not fill omitted input fields. The product
Root requires an actual selected directory and original reference. Empty
selectors are only for a trusted caller supplying independent captured custody
to the unsafe external-selection initializer.
