# Original recording inspection

`main.conduit` is a closed semantic Plot: a cadence requests an existing recorded
generation and projects it as an inspection Face. Host, storage, producer
selection and authority belong to the checked hosted IMAGE and trusted Root.

Repository proof entrances:

- `cargo xtask prove environment reported-generation`
- `cargo xtask prove environment recording-source`
- `cargo xtask prove environment recording-selected-host`
- `cargo xtask prove environment recording-owner-mask`
- `cargo xtask prove environment recording-owner64`

The Linux Source captures one explicitly selected immutable original JSON record
before Play and retains its exact reported-generation Info, including every
sample in the latest sealed chunk (up to 64). It does not run a recorder or
authorize producer retirement. The independent generic Data16 profile retains
its existing limits. See [the extraction audit](../../docs/audits/environment-extraction.md)
for acceptance gates and proof limits.

Checked initialization supplies all fifteen fields explicitly, including an
actual selected directory and original reference at product Root. Empty
selectors are only for a trusted caller supplying independent captured custody
to the unsafe external-selection initializer. No tail is silently selected.
