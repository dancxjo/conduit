# Womb

Crib makes Bodies; Womb makes member Seeds for an existing Body.

`main.conduit` is the ordinary checked Plot for preparing a new member Seed for
the same Body. It invokes `womb/prepare`, whose exact Kind, typed Fore and Host Call
identity are distinct from the existing independent-Body `creche/prepare`.
It contains no target, builder, filesystem, credential or deployment binding.

The request is a 32-byte reference to retained owner-admitted state. The owner
must bind the actual producing Body/Plan/Play, checked Host configuration,
current invitation, effect authority, and finite work/storage/evidence limits.
The reference grants no authority. Host configuration uses existing make
catalogues and `check_joining_host`; preparation must not call Birth or assign
an already-admitted Part to the target.

The 65-byte outcome retains the exact request, one classified disposition and
a digest of retained canonical evidence. Prepared means a Body-bound member
Seed was prepared. Unavailable builder, unsupported target, stale invitation,
preparation authority denial, cancellation, failure and invalid selection have
distinct codes. Authenticated membership admission and its refusal happen
later through the existing owner protocol. There is no deployment, Boot or
membership-success disposition on preparation.

The Back shares one finite transactional Host Call mechanism with Crèche.
Only successful kernel commit pins a request; output pressure retains the
completion without repeating effects. An installed owner must cancel and drain
platform work before kernel retirement and verify evidence custody before
completing a call. The kernel cannot infer custody from a digest.

Current proof checks the Source and executes the Back in the production kernel
with fixture completions. This does not establish installed Body execution,
artifact manufacture/acquisition, target launch or authenticated join. The
installed owner, canonical Face encounter and selected backend remain required
before offering Womb as a runnable product capability.

Repository contract checks enter through `cargo xtask check creche-preparation`.
The suite covers both preparation protocols; it does not establish a target
launch or membership receipt.
