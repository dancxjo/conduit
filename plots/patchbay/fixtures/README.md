# Retained compatibility fixture

`legacy-retained.conduit` preserves the former event/view Source for explicit
adapter regression tests. Browser and ConduitOS installed Patchbay use
`../main.conduit`, its canonical `FaceInteraction` Fore, and their actual retained
owner. The fixture does not select a production Patchbay route or admit effects.

General retained-application contracts remain available to other supported
Sources; this fixture does not justify a legacy fallback for canonical Patchbay.

The browser product now enforces that boundary during preparation: attempting
to prepare this retired Fore returns `patchbay-legacy-application-fore-retired`
before actor preparation. The old adapter, empty view poll and busy-view
projection are compiled only for Rust test fixtures. Native canonical slots
likewise refuse legacy events. Tour and the generic ApplicationView/Canvas
vocabulary retain their separate supported consumers.
