# Original tensor factory ownership in bounded tables

The generic numeric, affine Flow, linear Flow, embedding Flow and compact
factories move original complete capability offers and nested tensor bindings
from transient preparation maps into exact-sized Core bounded sorted arrays.
Original full placement and instance-count guards remain. Original shared tensor
Arcs are moved unchanged into the retained tables; no tensor/model/backing copy
or source/type normalization is introduced. Runtime selection does not grow an
array or retain a BTreeMap.

Each immutable builder now reuses its earlier complete validated Source-derived
offer for an exact implementation/Kind in the same global capacity mode. Every
occurrence still runs full original placement checks and instance counting. This
avoids repeatedly checking the same pure compiled Source catalog; it does not
accept a caller-authored offer or weaken a guard. Catalog/checker and transient
preparation maps remain upstream preparation, not free runtime storage.

Local inventories count actual identity/key String capacities, outer/inner array
capacities and complete retained offers. Borrowed shared tensor Arc traversal
lets the aggregate deduplicate actual resource roots/descriptors/backings across
factories. Tensor/model Arc payloads, allocation roots/headers and bookkeeping
are separate from local array/offer payload. Overflow/unsupported inventory is
refusal, not zero. Factories and planning-only data may drop before Play, but
their preparation peak still requires prior admission.

The actual archived 958-placement Plan test pins both original layout files,
all original f32 model bytes and three original feature buffers. It admits all
36 actual descriptors (33 slices sharing the original model backing), checks
every visited shared resource pointer against its original, and verifies each
factory's local inventory against allocator retained payload. The empty compact
branch is explicitly only an empty-owner test for this original Plan.

The same gate freshly admits the complete archived ModelSignature through its
prepared Native family and adopts the complete original model. It composes all
36 resources, original Plan, literal Source, full original Plan JSON and original
signature frame through `PreparedNumericResourceOwners`. The aggregate retains
exact original pointers/order and counts model/descriptor/buffer allocations
once by identity; all three one-under limits refuse before allocating. It
reports 87,003,938 retained payload bytes, 81 shared allocations and six byte
backings; the only new aggregate handle arrays request 320 bytes. Shared Arc
headers/bookkeeping/stack are separate; this is not a complete working-memory
admission or model-to-Source semantic correlation proof.

Measured preparation requests are retained as measurements, not promoted into
upstream admission. The cached-offer path lowers generic numeric cumulative
requests from 7,302,764,135 to 946,479,160 bytes in this pinned test. Actual
trained public driver/session, all remaining upstream preparation and attended
#5218 acceptance remain separate. No recurrent computation runs in this gate.
