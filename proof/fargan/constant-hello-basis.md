# Unchanged original Hello constant basis

`CommittedConstantBasis` borrows the actual opaque committed word-pitch owner.
It preserves the complete original event and exact original cycle only where
that ordinal's original and realized events are equal and no varying pitch
admission exists. It refuses unknown cycles, varying ordinals, missing events
and equal-byte material at a foreign owner address. It does not manufacture a
linear trajectory or a temporal approximation report.

The copied actual four-revision fixture prepared four Hello constant bases and
six original Travis trajectory bases. Each constant cycle was passed through
the existing executed Speech-to-Audio Source conversion and compared byte-exact
with the independently verified ten-initializer receipt. All six previous
complete Source/DSP golden frames were unchanged. One test passed in 43.42s;
all pinned SDK, original commitments, Source and fixture inputs were unchanged.
The receipt retains complete original events/cycles, four Source bridges and
corresponding initializers. It is component evidence, not a full model run or
listening/phoneme identity proof.

Evidence lives in project `outputs/fargan-constant-hello-basis/`; `run.py` is the
copied fixture reproducer against the pinned manual root SDK. Production Type
identity is not equated with that manual SDK. Final production transfer still
requires canonical bytes and fresh admission through production bindings.
