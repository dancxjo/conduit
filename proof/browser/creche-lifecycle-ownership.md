# Retired Crèche lifecycle proof ownership

Crèche is a redirect-only, zero-body entrance. Workspace owns birth,
membership, retained bodies, and resident execution. This map records where
each still-current contract from the retired standalone lifecycle specs is
proved; removing an old spec name does not remove its evidence.

| Retired proof contract | Current owner | Disposition |
|---|---|---|
| Birth naming, search, exact selection, reload persistence, review basis, receipt identities, canonical inventory bytes, and narrow layout | `workspace-arrival.spec.mjs` | Proved on the Workspace-owned birth surface. |
| All 24 naming traditions, editable suggestions, source editor semantics and geometry | `workspace-birth-naming.spec.mjs` | Migrated intact to Workspace Birth. |
| Gallery handoff, stale restored selection, installation, removal, and reload | `workspace-library.spec.mjs` and `creche-workspace-continuity.spec.mjs` | Proved against the retained Workspace body. |
| Redirect-only Crèche and absence of lifecycle runners | `pages-front-door.spec.mjs` and `executable-tour.spec.mjs` | Supersedes Crèche-ready, direct stepper, first-host, graduation, clear-and-rebirth, and standalone-runtime assertions. |
| Canonical three-form birth, Patchbay replan/play/cancel, exact placement inspection, kernel signs, and retained evidence | `workspace-body-execution.spec.mjs` | Body evidence now originates in Workspace. |
| Rosehip measurement plot, threshold, history, and cancellation | `workspace-body-execution.spec.mjs` | Migrated without changing the Patchbay execution boundary. |
| Independent browser hosts, membership, replay refusal, mixed parts, loss, and replacement planning | `workspace-body-execution.spec.mjs` and `workspace-membership.spec.mjs` | Birth evidence originates in Workspace; the comprehensive membership owner remains Workspace. |
| Browser, microcontroller, native-computer, and ConduitOS target selection, fabrication, and Body-bound handoff | `creche-*.spec.mjs` through the Workspace `Add a host` surface | The target catalog, adapters, and runner remain shared standard machinery; Workspace supplies the current Body and admission boundary. |
| Retired Tour scenarios that drove the standalone Crèche stepper, direct routes, or graduation | Workspace lifecycle specs plus the Workspace-hosted machine specs above | Removed from the active Tour shard; the surviving target-neutral catalog/cancellation/delegation tests remain active. |

The retired Crèche-only expectations—`Crèche ready`, `/creche/birth/`, direct
workflow steps, graduation controls, and standalone evidence download—described
the removed runtime rather than a current product contract. Machine fabrication
and configuration retain their historical spec names and CI shard for
continuity, but no longer imply Crèche lifecycle ownership.
