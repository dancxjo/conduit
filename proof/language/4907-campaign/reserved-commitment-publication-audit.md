## Remaining Current dependency publication seam

PreparedCommittedDependency public getters currently expose owned Native request/result/admission/arc and complete retained lexical tape. Session stores full owned Native admission/tape. A no-growth publication needs the same full values shared in preallocated immutable slots, rather than cloning at append. A private shared committed snapshot (admission + arc + existing shared lexical + actual replay/evidence) can be prepared before mutation, captured by session/receipt via Arc/Rc clone, and preserve old snapshot in finite history so replacement does not drop the last Native/storage share during Play. Current remains borrowing session and receipt, with exact full comparisons and existing stale/correction rules, never current=true.

The unknown dependency query cannot simply be precomputed at outer preparation: it includes the actual future BeamCommitRequest/result, chosen arc and exact lexical token. Generic PreparedNativeAdmission already handles actual optional/sequence law closure, but current generated prepared Native decoder explicitly rejects payload variants and sequence/optional shapes (generate_prepared_storage.rs:185–208). Actual LanguageDependencyHead is root | token LanguageAnalysisTokenRef; LanguageDependencyRelation.subtype is optional bounded Text; query.token includes candidate sequence<=4, morphology sequence<=8 and optional prior_occurrence. Full LexicalTape additionally contains tokens<=128 and profile entries<=64. Consequently current Beam decoder cannot materialize a future LanguageCommittedDependencyAdmission/Arc/Token and may not be relabeled as doing so. Sharing the already admitted owner lexical tape avoids re-decoding its huge profile, but does not by itself satisfy owned typed query/admission getters.

Choose explicitly between a narrow generic prepared decoder extension for actual dependency-query closure (payload variant/optional/bounded active sequences, preallocated actual profile; preserve every Native law and refuse unsupported external leaves), or an audited opaque canonical/shared-view receipt redesign retaining full original typed custody with documented getter compatibility. Do not handwrite a Language decoder or expose raw fields to forge receipt. This is a real remaining prerequisite, not covered by Beam no-growth tests.

Core RevisionEvent/DependencyDelta lifetimes are also real: journal stores borrowed immutable events/deltas, owner commitment vector stores &'a PreparedCommittedDependency. Future proposal/stable/commit events and their exact arc/receipt must live in controller-owned finite stable storage at least as long as owner; cannot borrow temporary stack material. Events themselves are reference/scalar wrappers and can use preadmitted immutable identity/evidence text; future actual Arc needs lawful storage. A finite one-shot external once-publish slot may solve lifetime ownership, but no unsafe self-reference, leaking heap, resetting journal or fabricated proposal should be introduced. Journal append already uses preallocated event storage; do not replace its semantics.
