The complete original model-free run passed at checkpoint b6a20204a (fixture and its three new helpers unchanged on review), with 377 compatible sentences, 1571 paired targets, 628 prefix schedules, 3142 accepted transitions and 6652 checked feature queries. It retains 17 whole-sentence segmentation exclusions (49 pairs, 22 prefixes); original 394/1620/650 denominators and original quarantined reports remain unchanged. Reviewed actual fixture semantics:
- Inputs::read binds raw/train/profile/original-generator/request/cohort and Source pins before execution; Graphs builds checked ordinary SourceGraph entries from the actual Language source.
- Graphs::invoke retains actual canonical request/output, invokes the Source graph, then U::from_structured admits its output. - Causal arrivals prepare actual text and lexical owners and execute checked revision rebase, asserting reset unread/depth/heads and committed0. Full arm prepares separate full available text. No gold labels are installed as future heads/query features. Static offline supervision remains separate.
- lexical_preflight compares actual lexical ordered surfaces with raw-label surfaces and excludes only a whole mismatched sentence, both arms. Unexpected lexical/availability errors panic, rather than exclude. Exact coverage assertions run before terminal report.
- Independent raw-train-review.json checks every original sentence's FORM/UPOS and replays its supplied bounded full class path against raw HEAD/base-DEPREL annotations. This is independent annotation provenance, not a second Source runtime. Crosslink report verifies request/observed membership, supervision, Source event references and every semantic filename/ordinary SHA blob.

No fitting, learned search, runtime commitment, abstention quality, natural arrival timing, installed outer controller, physical speech or heldout quality is proved by this run.
