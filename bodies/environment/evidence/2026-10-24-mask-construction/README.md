# Ordinary seven-segment Mask construction

Make now checks and expands the reviewed seven-segment Mask Source, admits its
Mask role, and invokes the ordinary planner against caller-supplied current
offers, Bases, authority, connections and explicit Fore queue bounds. Checking
projections never become advertised implementations. The resulting
`PlannedMaskPlot` retains the exact checked/expanded Source identity.

The focused `display_mask_source` CPU test seals an ordinary three-Fore Mask
plan using explicitly named fixture implementation descriptions. Removing any
one offered Back refuses placement. Removing the explicit Fore bounds refuses
planning. Fixture offers are not initialized renderer owners or physical proof.
All twelve existing `display_output` tests also pass; strict Clippy passes for
both test targets and the `native_owner` example. The existing public
`cargo xtask prove environment display-output` entrance includes the new test
and lint target; the full public suite was not rerun for this construction delta.

This does not install a renderer, implement an interaction Back, admit a clock,
bind a Face reader or create a Body Mask route. It starts no Play and flashes
no MCU. Actual initialized Mask implementations and combined sampling/output
memory admission remain the next execution boundary. The current operational
firmware is unchanged.
