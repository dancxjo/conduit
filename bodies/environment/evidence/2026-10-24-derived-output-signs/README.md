# Derived output sign backing

The pinned four-node/five-cord output graph has one bounded input and one refusal
Fore. Each admitted input can cause one ingress record and at most three
refusal-delivery records. Two Fore closures, four completions, two conservative
fault records and cancellation are retained. An 18-record conservative commit
reserve covers consumption, closure/fan-out, host request/cancellation, terminal
publication and fuel. The independently linked Plan's item/byte minima also
apply. Arithmetic or capacity overflow refuses before storage/driver transfer.

The exclusive caller counts every input, including brightness refusals, and
stops at its first kernel/service failure. The native execution context retains
this limit and refuses a larger run even if a caller presents a larger native
write allowance. This is a cooperative admitted owner contract, not hostile-code
confinement or a grant of membership, caller or GPIO authority.

For the existing two-input native diagnostic the CPU64 profile needs 36 ordinary
and 10 remote records: 960 backing bytes versus 11,264. Target record sizes still
control the MCU count/backing. The ordinary kernel and its retention policy are
unchanged: required evidence cannot be evicted; optional diagnostics leave an
explicit gap. Differential tests compare the complete emitted event trace and
all required retained records/remote identities with the previous 256/256 store
for writes, one/two refusals, pending cancellation and failed Host completion.
These runs allocate nothing during execution. Too-small item/byte/remote stores
refuse before consuming software. Thirty-two focused tests, strict scoped lint
and the display-ready ESP32 link pass. Root-test lint permits the same existing
dead-code items included from target modules.

This is not a continuing Mask retention/handoff proof. A longer lifetime must
admit its own bound or an explicit evidence handoff; old mandatory records are
never silently reset. No combined sensing/rendering or physical delivery is
claimed. Existing physical captures predate the reduced stores.
