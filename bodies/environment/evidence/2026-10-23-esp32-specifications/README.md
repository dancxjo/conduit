# ESP32 construction specifications

`cargo xtask prove environment specifications` passes for the Pico sensor and
sensor/browser compositions and the corresponding ESP32 HW-463 compositions.
All use the shared Host/Body checkers and canonical round trips; imported
seven-segment Mask meaning also passes its ordinary checker and role admission.

The first ESP32 draft refused with `MissingMakeDescriptor`. The final Host pins
the exact package descriptor. Only the registered kernel/signal Back is selected.
GPIO27 capture, monotonic time, display, retention and AP remain finite resource
requests, not manufactured offers. The generic WROOM signal builder is not the
climate diagnostic builder. No build, Spore deployment, minted Body identity,
authenticated membership, runtime admission or device start is claimed here.
