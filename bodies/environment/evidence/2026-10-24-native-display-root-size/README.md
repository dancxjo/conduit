# Native display Root bounds

The release build includes Root-owned GPIO18/19 output readiness. The retained
provider has not been selected into a Mask Play or used to transmit packets.

The saved size probe is an internal CPU fixture: it appends the current output
identity to a historical public Root advertisement using inert pins, then uses
the actual bounded encoder. It found an 8,731-byte diagnostic frame and an
8,198-byte maximum-counter admission envelope. The bare advertisement remains
capped at 8 KiB; the admission envelope reserves another 320 bytes, and the host
carrier admits 12 KiB frames.

The supported release build passes the unchanged 28 KiB stack floor with 28,836
bytes. Moving 384 bytes between the existing Root arenas preserves the 112 KiB
Root and 72 KiB SDK totals. Measurement hashes bind the source fixture, probe
and linked ELF. These records prove size/link bounds, not hardware execution.
