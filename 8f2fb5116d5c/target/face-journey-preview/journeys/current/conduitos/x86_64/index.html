A Body, its Patchbay, and its Face

Arrive at Crèche, birth a Body, start its work, inspect the live planned graph, and stop it. Each screen was captured from one keyboard-driven guest session.

Emulator evidence from source 6c406a4295b098a4e7a0001dc65418d5914aab51. It does not establish physical hardware operation or human enactment.

  1. Arrive at Crèche

    You do: First boot. The user sees a name field and locally available Plots.

    Crèche is open before any Body exists.

    What changed: A fresh Host and Boot have presented the first Face.

  2. Birth a Body

    You do: Birth. The user activates Birth after reviewing the Crèche Face.

    The selected Body is born and resting.

    What changed: Birth retains the Body without silently starting a Play.

  3. Wake it

    You do: F4. The user presses F4.

    The same Body has accepted Wake.

    What changed: Wake is a distinct lifecycle transition.

  4. Plan its work

    You do: F5. The user presses F5.

    An exact Plan now names gears, ports, and cords.

    What changed: The graph comes from the admitted Plan rather than a gallery specimen.

  5. Start Play

    You do: F6. The user presses F6.

    The Body awaits keyboard input in its admitted Play.

    What changed: The Body identity persists across Wake, Plan, and Play.

  6. Go Home

    You do: Escape. The user presses Escape.

    Home opens while the Body continues to exist.

    What changed: Navigation changes the Face, not the Body identity.

  7. Open Patchbay

    You do: Tab · Enter. The user selects Patchbay in Home and presses Enter.

    The resident Patchbay becomes the foreground application.

    What changed: The same Body and Plan remain current.

  8. Inspect the Face

    You do: F2. The user presses F2.

    The native Mask presents the current semantic Face.

    What changed: Content, actions, and structural relationships are projected from the running application.

  9. See the live diagram

    You do: F3. The user presses F3 within the Face.

    Cards show planned gears and ports with visible cords.

    What changed: The diagram is rendered from this Face’s exact graph subjects and endpoints.

  10. Stop the Play

    You do: F8. The user requests Stop through the Face with F8.

    The same Body is resting after Stop.

    What changed: Stop leaves the Body available for a later Wake.
