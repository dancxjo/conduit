# Prepared Source checking through an ordinary Host Call

`check.conduit` forwards a bounded S1 request to `language/source-check` and
returns the exact typed descriptive report, a distinct refusal, or
`not_prepared`. The checked Source is never installed or executed by this Plot.

The reference Host prepares an explicitly authorized immutable Source/context
before installing its immediate provider. Play only matches and copies bounded
canonical packets; it does not invoke a compiler, access files or allocate
inside the provider. One shared request schema and reply schema accompany the
finite prepared value nodes. Changed Source/context and unknown unprepared
requests do not acquire access or trigger hidden compilation.

These CPU fixtures use the existing native Source slot, selected Host Calls and
ordinary planner. They cover actual valid/invalid compiler results, exact typed
bytes, Host Call signs, missing/forged grants, stale provider/Boot/resource
identity, cancellation and allocation-free immediate reads. The static authoring
declaration creates no provider, grant or Ready offer.

Compiler/catalogue/Root preparation custody remains independent of retained
packet bounds. These tests do not prove complete managed IMAGE workspace
admission, process containment, physical behavior, product owner action routing,
or #6447 completion. #6449 independently owns candidate workset adoption.
