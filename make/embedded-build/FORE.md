# Local fore assignment projection

`generate_fore_native_plan` is the explicit Make opt-in for a complete sealed
plan with local external fore ports. It independently lowers that plan and
returns its generated kernel plus exact local fore pins. `encode` emits schema 7;
`layout_requirements` provides the matching resident record inventory. The legacy
generators and encoders refuse local fore rather than inventing network lines.

Each ABI digest covers the checked value kind and contract, abnormal kind,
temporal contract, track, quantity profile and admitted item/byte capacities.
Endpoint, cord, direction and front-port identity are pinned separately. The
resident profile must be produced independently of incoming assignment bytes.
Consumers must retain the typed lowering for value admission: an ABI digest is
neither a value validator nor authority to submit input or perform effects.

This profile refuses fused activation entries, remote endpoints, selected lines
and capacities beyond sixteen local fore ports. It creates no peer, membership,
line or native possession. The checked-Source integration test exercises ordinary
planning, deterministic encoding, contiguous and borrowed decoding, ABI changes,
capacity refusal, unsealed-plan refusal and legacy-path refusal. Physical display
execution and continuous sensor/Mask composition remain downstream obligations.
