# Prepared native Lucide masks

`lucide-map.json` maps existing `FaceIconKey` values to the pinned, licensed SVG
subset in `mechanisms/implementations/bounded-lucide`. Semantic keys/wire tokens
are unchanged. These resources replace original native approximation drawings.

`lucide-192.bin` contains exactly 23 packed 192×192 one-bit silhouettes (105984
bytes), ordered by the map. Coordinates match the existing eighth-pixel icon
coverage contract. The renderer retains its fixed 4×4 per-pixel coverage blend;
lookup has constant work and no runtime asset loading, parsing or allocation.
The asset is read-only executable data; no new graphics commands are introduced.

`lucide-receipt.json` records upstream, input hashes, pinned Chromium rasterizer,
threshold, output digest and byte count. Internal preparation uses
`targets/conduitos/tools/generate-lucide-icons.mjs` with the repository browser
proof dependencies. Review and commit regenerated bytes and receipt together.
Rasterizer changes require explicit regeneration/review; compilation does not
need a browser. License notices remain beside the vendored SVG corpus.
