# Committed external Fore evidence

Ordinary installed execution mints a borrowed `CommittedForeValue` only after
its actual scheduler exposes a committed remote Cord offer. Preparation pins the
exact immutable Fragment, current child Play, sealed output Fore, producer port
and lowered numeric Cord/endpoint. Each output tracks the next sequence; replay,
regression and exhaustion refuse before another witness can be minted.

The witness is affine and callback-borrowed. It copies neither Source metadata
nor payload and cannot outlive the actual execution callback. Its public scope
is inspectable; neither those descriptions nor an old `ExternalForeDelivery`
can construct commit evidence. The legacy delivery object remains an effect
request. Default dispatch preserves the existing Value and Flow adapter hooks.

Commit evidence grants no Base possession, Host Call, Body membership, native
resource use or durable recording. A consumer still needs independently admitted
execution/effect authority and must validate its expected scope, edge and replay
state. This hosted contract is not constrained native Fore assignment, MCU
installation, display construction, Root workspace admission or physical proof.

Owning checks exercise actual installed Source-to-Cord execution, pre-commit
cancellation, recurring Flow and legacy dispatch, plus same-Host child-Play
identity separation. Compile-fail contracts reject delivery-to-evidence upgrades,
affine duplication and retaining a witness beyond its actual lifetime.
