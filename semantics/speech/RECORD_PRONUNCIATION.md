# Committed lexical pronunciation

`cargo +stable xtask check record-pronunciation` checks a finite UK nonrhotic
profile for “a record” and “we record”. Language-owned committed dependency
facts select the noun or verb pronunciation. Speech Source projects canonical
IPA and explicit stress, then the existing compact formant path realizes it.
This supplied-graph proof does not claim learned parsing or general English.

`CommittedRecordPronunciation` borrows `CurrentCommittedDependency` from the
same live analysis session. Selection, exact source/token occurrence, full
lexical profile, dependency arc and actual commitment must match. Receipt
preparation alone cannot grant current authority. Superseded references,
foreign varieties and inventories missing a required phoneme refuse; none
silently switches to a guessed lexical pronunciation.

The immutable checked pronunciation Source is reused for both preparation
replay and ordinary installed StdHost Plan/Play. Complete canonical output
bytes are compared. The compact proof retains exact carrier custody and compares
only the record PCM span, excluding the different prefixes as a confound.
Dictionary spellings and declared phonetic realizations remain separate; authored
synthesis durations are not dictionary measurements. No phoneme/source evidence
is rewritten. Existing no-parser text synthesis remains explicitly labelled
`reduced-heuristic-compact-text@1`.

This implements the bounded consumer for #5725 under #4907. Local proof and
required Candidate, Integration and stable publication remain separate gates.
This contract does not prove physical playback, naturalness, a learned lexical
parse, vocative realization (#5755), or neural carrier realization (#5726).
