How to read proof classes

Source capability says code and deterministic contracts exist. Browser and emulator proof say that an exact execution was observed in that environment. Physical/HIL and human enactment require their own receipts. Released-product proof says an accepted commit crossed the release boundary; it does not silently upgrade the other evidence.
