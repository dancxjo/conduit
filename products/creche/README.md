# Crèche product ownership

This root records Crèche as a product owner. Its current browser realization
remains under `targets/browser/host` until #2277 moves product-specific browser
source across that boundary. This issue does not duplicate or alias those
sources here.

Crèche consumes canonical Forms from `forms/` and authors workload revision 0;
it does not own Form meaning, a scheduler, or a permanent Body work surface.
