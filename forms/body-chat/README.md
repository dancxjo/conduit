# body Chat

body Chat is an ordinary form through which a human converses with one current
body. The form owns no model provider, transport, operating system, DOM,
microphone, or speaker identity.

The body supervisor supplies `body/conversation-context` from matching bounded
lifecycle, presence, plan, line-availability, and sign truth. A generic host
does not advertise that source. The prompt gear retains at most 16 explicitly
labeled human/body messages and creates each model request from that bounded
history plus the latest canonical body snapshot. The selected model remains a
replaceable, stateless realization and advertises zero provider-side history.

The initial form presents text interaction and generation. Requests to perform
an action remain text: the prompt explicitly forbids claiming an action occurred
merely because it was requested. A future typed action form may manifest
Patchbay or an inspector under its own admission and authority.

Current executable proof checks the canonical form, bounded history and body
projection, transport-neutral Webchat compatibility, hosted prompt realization,
and repeated local-model flow. This does not establish live voice, physical
audio, ConduitOS graphics, or a five-host demonstration.
