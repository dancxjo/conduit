Add an item to Groceries

The browser joins an installed Todo Body, wears its browser Mask, and adds “Pick up prescription.” The new item appears in a fresh Face and Show from that same Body.

This run proves one browser Add action. It does not prove the other Todo actions, the native or spoken Masks, lull and wake, a complete multi-host journey, or stable release acceptance. The installed owner was built from source 99399c157; the packaged browser runtime came from f7778c323. The Handbook UI bytes match clean source 99399c157, so this is explicitly cross-source development evidence.

What happened

  1. An installed Linux Host offered Todo during Crèche Birth. The owner selected it and gave the new Body a Groceries list.
  2. Chromium joined that Body through an authorized owner window, inspected its wardrobe, and selected the browser Mask.
  3. The owner started a Todo Play. The browser received an available Add action. The person entered “Pick up prescription” and activated it.
  4. The owner accepted the action. The browser received a different Show with the new item, and a separate owner Face read confirmed that the same Body contains it.
