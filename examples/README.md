# Conduit examples

Canonical source uses the `.conduit` suffix and the face/back/cell surface:

- `hello.conduit` — Program 1 text pipeline;
- `greet.conduit` — Program 2 parameterized reusable form;
- `clock.conduit` — Program 3 invocation and time source;
- `count.conduit` — Program 4 startup, closing flow, and current value;
- `signal-demo.conduit` — Program 6 unchanged multi-host semantic form;
- `socket-client.conduit` — Program 5 duplex source shape, explicitly deferred
  until an external `net/websocket` operation is accepted.

The `.form` files and `hello.panel` use the older explicit `form 0`
compatibility parser. They remain byte-for-byte fixtures for accepted kernel,
browser, firmware, carrier, composite, and evidence identities. They are not
examples of the canonical source surface and must not be silently reinterpreted
or rewritten under the canonical parser.

Placement files are Plan-side inputs for those retained compatibility proofs;
they are not semantic Form source.
