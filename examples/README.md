# Conduit examples

Canonical source uses the `.conduit` suffix and the face/back/gear surface:

- `hello.conduit` — Program 1 text pipeline;
- `greet.conduit` — Program 2 parameterized reusable form;
- `clock.conduit` — Program 3 invocation and time source;
- `count.conduit` — Program 4 startup, closing flow, and current value;
- `signal-demo.conduit` — Program 6 unchanged multi-host semantic form;
- `socket-client.conduit` — reusable external `net/websocket` duplex face;
- `webchat.conduit` — Program 5's bounded browser client and std listener,
  expressed as canonical face/back/gear Forms.

`hello.panel` and the placement files are retained proof inputs, not Form
source. Historical pre-canonical Form bytes live under `proof/fixtures/forms/` so
they cannot be mistaken for programs users should author or run.
