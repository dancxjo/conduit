# Performance and representation investigations

Conduit optimizations must preserve the checked semantic contract, identity,
authority, pressure, cancellation, and finite admission boundaries. An
investigation or local measurement is not automatically a production speedup.
Start with [STATUS](../../STATUS.md) for accepted capability and the
[canon](../conduit-canon.md) for invariants.

## Preparation and reuse

- [Source dependency reuse](source-dependency-reuse.md): exact consulted catalogue dependencies versus conservative invalidation
- [Near preparation reuse](near-preparation-reuse.md): immutable fragment retention and cache refusal
- [One numerical child across Fore values](numerical-fore-session.md): finite reusable child sessions
- [Thermostat Body values](body-value-session.md): replacing repeated prepared children with an admitted reuse profile

## Execution, allocation, and inspection

- [Compact output ownership](compact-output-ownership.md): explicit pre-admitted buffer transfer, not universal zero-copy
- [Fusion inspection](fusion-inspection.md): retain logical Gear correspondence when physical dispatch is grouped
- [Replacement cost facts](replacement-cost-facts.md): measured candidate inputs, not a replanning policy
- [Reluctant replan observation](reluctant-replan-registration.md): supported benchmark and profitability limits
- [GPU feasibility](gpu-feasibility.md): negative per-Gear result and separate unproven whole-frame hypothesis

These documents each own a scope-limited measurement or contract. Follow their
commands and evidence prerequisites exactly; do not generalize their result
to another target, hardware profile, model, or release. See the
[documentation policy](../documentation-policy.md) for proof terminology.
