# Selected Source Back owner context

Prerequisite for #5217's ordinary Source component library. A selected canonical
Back previously retained one checked Plot but expanded it using the caller's
private Plot table, structured Types and exact initial values. A same-named
caller helper could replace the owner's helper; missing metadata also prevented
valid construction under the owner's Native laws.

The existing Back catalogue now retains the complete immutable checked owner
for each admitted Kind, bounded by its unchanged 64-Back catalogue limit.
Expansion uses that owner's private definitions, Types, literals, physical
catalogue and invariant metadata. Compiler-owned per-Gear provenance selects
that owner's retained Native laws at final construction validation; ordinary
caller Gears retain caller rules. Source spelling and path names cannot grant
this validation scope. No global union of imported constructor authority is made.

Cycle detection considers the complete checked private namespace. Equal root
names or checked root identities can coexist when their helper definitions
differ; genuine recursive Back selection still refuses. Duplicate registration
returns its existing typed refusal without replacing the admitted owner.

`insert_with_catalog` also retains an explicitly admitted private primitive
catalogue, including when the caller lacks that Kind or has a different contract.
It does not modify the caller catalogue.

Focused compiler tests cover same-named helpers and roots, renamed imported
Types, private-law isolation, duplicate registration and genuine recursion.
This changes compilation/preparation only. It installs no Host capability and
contains no DSP evaluator or physical effect. The five focused regressions are included in `cargo xtask prove recursive-recovery`.
Local validation passed all five, 477 Plot/Text library tests (one existing
ignored test), strict Plot lint, formatting and patch checks.
