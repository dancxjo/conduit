# Independent bounded Audio control trajectories

Issue #5745 adds an Audio-owned set of 1..8 controls, each with a nonempty bounded authored source scope/control identity, explicit quantity domain, U16 priority and an existing 1..16-segment exact trajectory. Source scopes are authored identities, not authentication or measurement grants. Original trajectory anchor, provenance, fractions and policies remain unchanged.

The collection's query is exact abstract time. Each original trajectory evaluates independently through accepted checked Source, without a renderer sample clock or phone/word boxes. The Source domain projection and checked domain-match law enforce each declared domain. Different source scopes can overlap. Duplicate source/control pairs and conflicting quantity domains for the same logical control refuse.

Conflict policy is explicit: refuse overlap, or select the unique highest priority and refuse equal highest priority. A checked Source expression owns the U16 comparison. Lower-priority ties do not displace a unique higher winner. Every original evaluation remains in the private receipt, including controls not selected; selected indices refer to original entries. The only admitted gap policy refuses any original control without coverage, identifying its index. Foreign anchors and unsupported arithmetic profiles retain existing typed trajectory refusals. Gap/domain admission precedes conflict selection deterministically.

Domains reuse existing exact frequency, cycle, amplitude and power Types. Energy-level examples use the declared relative-power domain; formants use independent frequency controls; envelopes use amplitude. No Joule, referenced-dB trajectory, log-frequency interpolation or new numerical profile is inferred. Step and linear interpolation retain their original distinct laws and explicit right-continuous/final-included endpoints. Existing U32 step eligibility covers real formant frequencies; values outside the selected linear/step profile refuse rather than clamp or approximate.

Storage and traversal are bounded by eight controls and sixteen segments per control, with bounded source/control/provenance text. There is no history growth, worker, cache, device or new crate. Receipts expose the complete original canonical collection, exact query bytes, all per-control original/evaluation receipts and checked priority/domain projection executions. This allocating preparation seam is native Source/component conformance, not a kernel Play Back or physical output claim.
