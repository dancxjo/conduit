# Installed numerical projection proof

Issue #5531's fixture is `targets/std/tests/numerical_installed_play.rs`.
One checked Source uses exact `0.3` with zero-error and one-unit-error consumer
requirements. Its external result Fores declare the installed Back's exact
8192-byte envelope. StdHost prepares source-specific certified offers; an actual
Plan selects the installed rational and binary64-nearest factories separately.

The fixture executes that Plan through StdHost and captures canonical receipts
at acknowledged external Fores. Both retain rational source 3/10. The exact
receipt has equal source/lower/upper and zero error; the binary64 receipt has a
different exact target denotation and a nonzero error certificate. Full receipt
bytes also match the selected certified strategy. Kernel value-store capacity
must remain unchanged.

Selecting the binary64 offer for the zero-error consumer must refuse planning;
the accepted Plan identity remains unchanged. Changing the selected artifact
must refuse execution without publishing output. Printed evidence retains
Source, checked/expanded Plot, Plan, and per-run Play identities.

This is installed std execution proof. It makes no hardware, browser, numerical
speedup, symbolic arithmetic or parent-wide acceptance claim.
