# Candidates for the remaining native graph gate

Refs #5519, #5358, #5994 and #6257. The original gate needs actual compact
Patchbay on a real native Body/Plan, source-linked selection/Details and
>12-link continuation. Multiple independent small graphs or boundary bindings
cannot be added together to manufacture that result.

The [checked native graphical Mask](evidence/checked-native-mask-candidate-20261022/)
has four Gears and **four internal Cords**, separately from three boundary
bindings. The installed product diagram entrance checks and expands this exact
Source successfully; its binary hash matches the previously retained Source3217
checker. It therefore rules out this existing Mask Source as a shortcut to the
larger-graph gate. It does not establish actual native Patchbay admission or
selection of that Mask. Other possible Mask Sources are not universally ruled
out by this one measurement.

The [existing Vision candidate](evidence/checked-source-vision-candidate-20261022/)
has eight Gears and **14 internal Cords**, separately from two boundary bindings,
through the same checked expanded-authoring entrance. It remains a meaningful
Source candidate, not permission to run Vision, a model/native execution claim,
or proof that the normal Patchbay can select it. Recursive selected Plot-Back
expansion is not inferred from this authoring graph.

The native preparation path currently takes graph targets from other resident
BodyPlan Plots and requires target Plan identity. #6257 retains the bounded
proposal to inspect explicitly authorized checked Source with target Plan/Play
absent, keeping the actual Patchbay Body/Plan real and granting no execution or
owner effects. It stays unbranched until #6255/#6252 integration handoff. The
original #5519/#5358 requirements remain open; an already admitted suitable
planned graph would still satisfy the gate without that optional extension.
