# Missing visual policy and readable canonical controls

The shared visual admission path selects canonical Phosphor when a requested
Look has no visual facet. It reports `MissingVisualFacet` in the existing
`PhosphorFallback` outcome. The requested resource remains intact, including
its spoken and generative facets; its visual availability remains `Absent`.
Selecting visual default data neither selects other modalities nor acknowledges
an actual Show. Impossible user/Host text limits still refuse.

A native CPU test supplies actual checked Crèche Source with `visual: none` to
the configured preparation entrance. It retains the same Face and every exact
action/argument control across the complete prepared scene. The test also
retains its existing unsupported-layout fallback and absent-Back negative cases.
This is a configured consumer test, not QEMU, scanout, physical or runtime evidence.

Canonical browser controls previously overrode the 16px Look body token with
13px action labels. They now consume the body token, with the existing browser
root/user minimum and admitted text scale. Supporting captions consume the
small-text token. The renderer also omits a redundant action-name heading when
an action has no arguments; its complete name remains on its button. This
cleanup applies to every Look and does not make Look select component topology.
