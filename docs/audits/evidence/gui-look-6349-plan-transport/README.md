# Complete Look Plan transport

The complete configured Look previously produced a 73,764-byte remote route
basis, rejected by the unchanged 40 KiB seal bound. An exact prefix-table
experiment still left spacious Editorial over that bound; it is not shipped.

`PlannedMaskPlot` JSON now uses the explicit
`conduit.face/mask-plan-deflate-json@1` Plan envelope. The existing pinned
no-std miniz implementation losslessly packs the complete ordinary Plan JSON.
The envelope retains its inspectable Plan ID, limits expanded JSON to 256 KiB
and compressed bytes to 64 KiB, and requires exact decompressor input consumption,
output length and decoded Plan ID. Ordinary Plan admission remains required.
Binary serde retains its original field sequence. Legacy unversioned JSON is
not a compatibility path. Source, Plan fingerprints and complete canonical Look
bytes are restored exactly; no resource is replaced by a claimed digest.
The remote seal, owner response, browser Line and delivery ceilings are unchanged.

Local checks: all eight actual Todo Look/recipe combinations restore equal Plans
with verified fingerprints. Their transported Plans are 13,367–13,803 bytes.
Eight configured-layout and twelve Mask/ensemble/transport tests pass, including
ten malformed envelope/stream mutations, oversized expanded input and negative
legacy JSON. See the retained logs. These are local encoding and admission
checks, not a fresh installed-owner, browser carrier or native execution receipt.
Private owner state and control traces are excluded.
