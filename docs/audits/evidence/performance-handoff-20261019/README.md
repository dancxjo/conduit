# Retained performance handoff records

The [ranked index](../../performance-work-breakdown-20261019.md) and GitHub tracker #6078 own the work breakdown. `issue-plan.json` maps all 37 actionable issues to acceptance criteria, dependencies, source branches and proof records. `origin-work-routing.json` records observed remote heads and the exact historical proof revisions.

`retained-files.json` hashes the supplied audit, selected exact-copy proof records and unchanged verifiers/controllers. These files retain their original source and scope, including historical release identities and excluded measurement families. They do not certify a newer source or release.

Private model/fixture inputs, raw local captures, ELF workers and build caches are excluded. A verifier requires its matching authorized raw input. Relative paths inside original records refer to the original evidence collection; they are not promises that the complete raw artifact is committed here.

No original quiet-family registration, controller, verifier or acceptance threshold was changed for this handoff. The issue-ranking documents are planning records, not performance measurements.
