Issue #5752 follows the accepted language dependency vocabulary in #5720. The existing `current_word_has_syntactic_link(vocative)` condition previously refused all syntax. A bounded consumer now compares that original condition with the supplied canonical `LanguageDependencyArc` and stores references to the original lexical tape, analysis, arc and variety. The existing bounded conjunction has an explicit `compare_conditions_with_syntax` entrance; callers supplying no syntax retain the existing refusal.

The migration supports only the unqualified UD `vocative` relation on the current complete word. A supplied unqualified different relation yields mismatch. Unsupported legacy kinds, relation subtypes and neighboring-word conditions refuse rather than collapsing language distinctions. Both arc endpoints must occur in the original prepared lexical tape and belong to the supplied analysis revision; the dependent must be the current exact occurrence. Expected and supplied varieties must match and have the source's language. No parser, punctuation rule, speech relation enum, acoustic timing or fallback is introduced. The receipt retains the language-owned relation, not another persisted syntactic truth.
