# Actual admitted record-read consumer handoff

The current retained Source already exposes `yellow-sampling.read_index: Count` and `read_result: RecordReadResult <=837B`. See `current-record-read-source-bindings-20261116.json` for actual selected Source/Plot/expanded IDs and freshly emitted bindings. No new Source CAS is needed to expose that read operation. Current device readiness and native carrier ownership remain separate gates.

## Reuse the existing codecs

- `conduit_core::encode_count(u64::from(index))` supplies the exact 8-byte Count input; do not invent text RPC framing.
- `conduit_resource_snapshot::read_result::decode(bytes)` validates the exact linked canonical schema and finite 837-byte ceiling. Its borrowed `ReadResult` has Recorded {index,captured_end,record}, Gap, End, Busy, Cancelled, RecoveryRequired and Unavailable outcomes. A record is at most 200 bytes. Preserve non-record outcomes rather than substituting old readings.
- `conduit_resource_snapshot::read_scan::RecordScanCursor` correlates the requested physical index, bounds the initial prefix, pins its first captured tail, and refuses wrong index/regressed tail/early End. It is allocation-free and grants no residence/generation/commit authority. Blue's physical store has 1264 slots. Keep physical indices distinct from observation sequences.
- `conduit_environment_runtime::recording::PreparedLogReader` is the actual production content decoder. Prepare once with `conduit_dht11_observation::ObservationContract::prepare()`. `prepare(context,contract,first_sequence)` pins an independently selected expected context digest; `prepare_content(contract)` recovers unknown contexts as DESCRIPTIVE CONTENT ONLY. Neither verifies a producer signature or authorizes history admission. The retained reader has 1536 inline context bytes plus separately reported `retained_backing_bytes()` for exact quantity composers; fund both.
- Feed each actual Recorded payload into `reader.read(record)`. Context frames must complete in order and match their context digest/schema/Form identities. `LogFrame::Sample` yields sequence, sampled_at_boot_ms, disposition, explicit sequence/media gaps and a BORROWED canonical observation. Copy or consume that observation before the next reader call. `reader.note_media_gap()` preserves a physical gap; `reader.finish()` rejects an incomplete final context. Do not silently skip it.
- Canonical observation fields are first-class Temperature and Ratio quantities, restored by `PreparedObservationQuantityForms`; packed bytes use the authored `DeviceDht11TemperatureForm` and `DeviceDht11HumidityForm`, two bytes each. Do not reinterpret raw bytes as ad-hoc centi-Celsius/humidity integers. Use the existing quantity decoder/conversion/Form contracts to make `MeasurementSample`.

## Provenance and clock boundary

`reader.context()` returns Body, Host, Boot, Plan, Play, stream, observation-type digest and first sequence from validated CONTENT. Compare against independently authorized residence/producer/history scope. A context digest, current authenticated media read, or matching incoming Body/Host string does not independently authenticate an old Boot/Plan. Unknown historical contexts must remain explicitly descriptive until the history owner selects appropriate evidence. The offline recovery tool is a parser example, NOT an admission/identity authority.

The exact recording clock is `producer-acceptance-boot-ms@1`: local acceptance in that recorded Boot, not sensor acquisition, Linux receipt or wall time. No conversion to Unix time without an independently retained clock relation. Preserve Boot and sequence identity through replay. Never date historical readings with the time they were received.

## Transport and pending custody

Use the existing same-descriptor `PicoForeCarriage::exchange`. Its callback receives scope-checked application bytes and precedes transport Accepted/Delivered. Validate/correlate and retain the complete finite result in one originally funded pending slot. Queue Full retains that pending payload and issues no next read; it is not ConsumerRefused. A genuine malformed/foreign/wrong-index result refuses without an application ACK. Root kernel/Face staging is not durable recording: no media erase, durable ACK or safe retirement follows from the exchange, queue acceptance or a successful graph render.
