# One canonical IPA constructor contract

This is the pre-implementation decision for [#5329](https://github.com/dancxjo/conduit/issues/5329),
a prerequisite to closing [#5260](https://github.com/dancxjo/conduit/issues/5260).
It selects the four static Value constructors in #5319. #5327's extra Host Call
does not supply runtime input, external state, authority or an effect: its
`IpaAdmissionHosts::prepare` already parses, resolves and encodes the outcome;
`execute` retrieves those retained bytes after checking a placement digest.
The reconciled literal constructors therefore use ordinary prepared Value delivery.

## Meaning and deliberate compatibility boundary

`SpeechPhoneNotation` is one supported universal phone spelling, not an observed
or contextually realized phone occurrence. `SpeechPhoneticTranscription` is a
universal event tape with separate phone, stress, length and boundary events.
Neither needs an invented language inventory. A `SpeechPhonemeNotation` is one
exact supplied definition resolved against a complete checked inventory/basis;
`SpeechPhonemicTranscription` resolves a complete tape against that same scope.
Equal-looking IPA never proves identity, membership, commitment or playback.
Decoding a Native candidate alone does not establish inventory admission.

The representation differences include request grouping, wrapper names and span
layout. The semantic differences include Value versus closing Flow, Source or
preparation refusal versus a runtime refused outcome, explicit universal profile
selection, and Host/resource eligibility. These cannot be repaired by a rename,
shape coercion or overload selected by the expected output Type.

The selected API remains `ipa-quoted@1`: neither draft API is an accepted release.
The `ipa-admission@1` request/outcome families, Host operation and Back identities
are not installed as aliases. Legacy shape-only `SpeechInventory` and foreign
wrappers must refuse at exact typed boundaries. A consumer of the superseded
draft must deliberately reconstruct and check the selected request and whole
scope; copying encoded bytes, renaming the Fore or extracting an `admitted`
payload is not a migration. No dynamic entrance is introduced without a separate
demonstrated runtime requirement and distinct public semantics.

The selected finite grammar retains 47 supported segments and four marks,
explicit aliases, at most 256 profile units/aliases and 256 occurrences,
64-byte unit spellings and 4096-byte phonetic bodies. A phonemic body reserves
two bytes for display slashes and is limited to 4094 bytes. At most 64 bindings
of at most eight units each are checked. Complete segmentation and membership
refuse ambiguity, partial inventories and foreign revisions/varieties.
Stress/boundaries cannot become phoneme definitions; length requires an explicit
phoneme binding. Unsupported is not a claim of invalid linguistic IPA.
There is no silent Unicode normalization; declared nasal aliases preserve the
original composed or decomposed spelling and evidence.
