# Patchbay visual Look resource

Patchbay's portable appearance data belongs to the canonical Source-checked
`LookInfo` contract in `conduit-face`. The built-in `conduit.look/phosphor@1`
resource provides bounded RGB roles for background, surfaces, structure, text,
emphasis, focus and status, plus finite typography/spacing/shape metrics.
Spoken and generative parameters are separate optional facets. Look has no
Face slots, actions, input bindings, component topology or provider authority.

The native stylesheet producer projects the admitted visual tokens into bounded
same-origin CSS. The browser nucleus transports the canonical Native value to
the mechanical browser binding, which checks the exact type profile and field
bounds before setting fixed paint-role properties. The old binary theme reader
and old serialized identities are retired, with explicit refusal rather than a
compatibility adapter. Current application packaging names the canonical module
and admits its actual finite byte bound.

Responsive breakpoints and grid minima belong to the renderer/component. They
are no longer transported as Look tokens. Color and typography preferences
cannot select or remove actions, alter keyboard mappings or replace semantic
reading order. Platform accessibility requirements and hard Host limits take
precedence over author styling. A missing facet or unavailable realization must
be exposed honestly, preserving a usable generic encounter where supported.

Appearance may change the selected rendering Plan or acknowledged Show. It does
not rewrite the original Body, Face, actions or semantic composition. Resource
identity, source, selected realization and actual acknowledgement remain
separate evidence. Native clipping, browser computed styling, focus and
contrast checks retain their own execution boundaries; passing admission alone
is not evidence of a rendered or physical result.
